Universal UMKM Pro v4.1.0 — Katalog Konsolidasi

Katalog pilihan usaha aktif berisi 25 jenis usaha inti, bukan 300 nama usaha terpisah. Variasi nama lama disatukan ke produk/variasi dalam kelompok usaha yang relevan.

Paket lama tetap di master dengan status nonaktif dan ID lama tidak dihapus. Data lokal pengguna (profil, produk tersimpan, transaksi, stok, pembelian, dan riwayat) tidak dihapus oleh file ZIP ini. Ekspor backup sebelum memperbarui aplikasi.

Resep bawaan adalah referensi awal yang belum diverifikasi. Periksa takaran, satuan, hasil jadi, susut, dan harga beli aktual sebelum mengandalkan HPP.
